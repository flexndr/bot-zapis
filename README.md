# Telegram-бот для записи клиентов в салон

Клиент сам выбирает услугу → мастера → день → свободное время и оставляет телефон. Без администратора, круглосуточно.

**Что умеет**
- услуги с ценами и длительностью, мастера и их услуги — справочник в начале `bot.py`;
- показывает только свободные окна, защищает от двойной записи;
- напоминает клиенту за 2 часа до визита;
- отмена записи клиентом («Мои записи»);
- уведомление администратору о каждой записи и отмене, команда `/zapisi` — список на сегодня и завтра.

**Запуск**
```bash
pip install -r requirements.txt
BOT_TOKEN=<ключ от @BotFather> ADMIN_ID=<ваш Telegram id> python bot.py
```
Записи хранятся в SQLite (`zapis.db` рядом с ботом).
